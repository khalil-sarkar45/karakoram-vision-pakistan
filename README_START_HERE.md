# Karakoram Vision Pakistan — Start Here

This is an independent project. It contains no Git history and does not modify the original master project.

## Windows PowerShell

```powershell
npm.cmd install
npm.cmd run build
npm.cmd run dev:full
```

Open: `http://127.0.0.1:8788`

## Before live deployment

1. Verify the TikTok URL, company registration details, licenses and every service claim.
2. Add a real Formspree or Google Forms endpoint in Pages CMS.
3. Add Google/Bing verification codes only after the correct accounts are ready.
4. Replace starter illustrations with client-owned photography where available.
5. Review prices, dates, permits and cancellation terms before taking payment.

Run `INIT_SEPARATE_REPOSITORY.ps1` only inside this Karakoram Vision folder.
